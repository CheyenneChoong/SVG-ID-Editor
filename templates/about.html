4. SVG Processing

  • Automatic ID : One click and every element of the svg will be ID.
  • Upload ID : Upload a .txt file containing the ID and conditions for identification of element.
    Format = Reference Colour,Attribute,ID,Final Colour (e.g. #FF0000,stroke,base,#000000)
  • Reset : Resets the SVG back to the original no ID version.
  • Test : Test mode allows for preview of the selected ID part. Hover over the ID card in the ID list.
  • Download : Download the SVG.
